meteo-mcp-rs

A fast, zero-API-key MCP server in Rust with an interactive MCP App weather & air-quality dashboard, powered by Open-Meteo.

Live demo

This is the actual ui/dashboard.html served by the MCP server, loaded straight from the repository. This page plays the role of an MCP Apps host: it answers ui/initialize and serves the widget's tools/call requests by querying the Open-Meteo APIs directly from your browser — the same requests the Rust server makes. Try the search box, the preset pills, and the refresh button.

Loading dashboard from the repository…

Inside Claude (or any MCP Apps–capable host) the dashboard is rendered from the ui://meteo/dashboard resource and the host proxies tool calls to the meteo-mcp-rs binary over stdio.

Install

Homebrew (macOS / Linux)

brew install gohyperdev/tap/meteo-mcp-rs

cargo-binstall (prebuilt)

cargo binstall meteo-mcp-rs

Cargo (from source)

cargo install meteo-mcp-rs

Prebuilt archives

github.com/gohyperdev/meteo-mcp-rs/releases

Configure in Claude Desktop

{
  "mcpServers": {
    "meteo": { "command": "/opt/homebrew/opt/meteo-mcp-rs/bin/meteo-mcp-rs" }
  }
}
